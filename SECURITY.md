# Security policy

TopNote is currently a personal test release. No commitment to a fixed security-patch timeline is made.

If GitHub private vulnerability reporting is enabled on this repository, please use it for a suspected security issue. Otherwise, ask the maintainer for a private reporting channel **without posting exploit details, secrets or private device diagnostics publicly**.

Ordinary feature requests and non-sensitive bug reports are suitable for GitHub Issues.

Never include a personal note, auth token, signing key or unredacted troubleshooting report in an issue.
